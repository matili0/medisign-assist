# Prepared corpus

The demo does not need the full corpus. For evaluation, extract the separate
`medisign-data.zip` at the repository root to obtain `data/LSFB_ISOL/`.
The prepared subset contains 6,055 usable medical pose sequences and the original
metadata/signer partition. It does not include the auxiliary pretraining poses.

The corpus is excluded from Git. See [reproduction](../docs/REPRODUCING.md) and
[source attribution](../NOTICE.md).
